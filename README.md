# Fieldwork

Installable phone app. Static files only: no server, so it never "spins up".
After the first open it runs entirely from your phone, even offline. Your data stays on the phone.

## Put it online (GitHub Pages, free, one time)
1. Create a new GitHub repo, e.g. `fieldwork`.
2. Upload every file in this folder to the repo root.
3. Repo Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
4. Wait a minute. Your app is at `https://<your-username>.github.io/fieldwork/`.

## Install on your phone
- iPhone: open the link in Safari → Share → Add to Home Screen.
- Android: open in Chrome → menu → Install app.

## Moving data
Settings (gear) → Copy backup, then Restore from backup on the other device.
